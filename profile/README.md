# HariNirVed | ViKi Sovereign Creative & Engineering Ecosystem

> **Sovereign, privacy-first desktop creative and engineering software suite powered by Rust, local-first architecture, and autonomous AI orchestration.**

Welcome to **HariNirVed**, the institutional home of the **ViKi Ecosystem** — a unified suite of sovereign desktop applications engineered for creators, engineers, visual artists, and architects.

---

## 🏛️ Sovereign Architectural Pillars

1. **100% Rust Performance:** High-throughput graphics pipelines built upon WGPU, egui, and native system bindings with sub-millisecond response latency.
2. **Local-First & Zero-Telemetry:** Total operational sovereignty. Your files, documents, and creative IP remain on your machine — zero cloud locking, zero invasive tracking.
3. **Model Context Protocol (MCP) Native:** Every application exposes deep, headless Model Context Protocol tools, enabling autonomous AI coding and design agents (like Antigravity) to inspect, generate, and edit workspaces programmatically.
4. **Cloud-Native Fleet Automation:** Continuous upstream synchronization and deterministic rebranding powered by [viki-ops](https://github.com/HariNirVed/viki-ops).

## ⚙️ Operations & Infrastructure (`viki-ops`)

The entire synchronization and rebranding pipeline across all 16 applications is orchestrated automatically via **[viki-ops](https://github.com/HariNirVed/viki-ops)** on GitHub Actions:
* **Zero Mac Strain:** 100% executed in the cloud on GitHub-hosted Ubuntu runners.
* **Zero Merge Collisions:** Deterministic overlay adoption on top of pristine upstream releases.
* **Automated Verification:** Sub-second AST/TOML validation gates enforcing clean branding and zero trademark residue.
